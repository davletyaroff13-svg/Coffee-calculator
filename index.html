Анализ ассортимента

Импорт продаж из CSV

Файл обрабатывается только в браузере. Ничего не отправляется в GitHub или Fusion. Поддерживается CSV с колонками «Название» и «Количество» (либо name и qty), разделитель ; или ,. Импорт обновляет план продаж по совпадающим названиям, а не складские остатки. Для выгрузок Fusion с другими заголовками понадобится сопоставление колонок.

Данные текущей сессии не сохраняются на сервере. Перед закрытием страницы экспортируй модель, если она нужна.

Мои данные на этом устройстве

Данные автоматически сохраняются только в хранилище этого браузера. На другом телефоне будет отдельная модель. При удалении данных сайта или приложения записи могут исчезнуть.

Проверяем локальное хранилище…

Файл резервной копии храните в надёжном месте: он содержит ваши закупочные цены и расчёты. Восстановление заменяет текущую модель после подтверждения.

Демонстрационные данные, не финансовая отчётность. Не вводите конфиденциальные сведения на чужом устройстве.
